# Pholver (web edition)

A 2D physics sandbox with Mechanics, E&M and Circuit tabs. Open `pholver.html` in a browser; nothing else is needed.

```
./build.sh          # regenerate pholver.html
./run_all.sh quick  # syntax + build + Node tests (seconds)
./run_all.sh        # everything including the browser tests (a few minutes)
```

Developers and Claude Code: start with `CLAUDE.md`, then `ARCHITECTURE.md`; design notes and the Rust backlog are in `IDEAS.md`.
